# ProjectHub — ระบบบริหารจัดการรายวิชาโครงงาน วิทยาลัยการอาชีพโพนทอง

เวอร์ชัน 1.0.0 (30 ต.ค. 2569) · ผู้พัฒนาระบบ : ครูสมควร สากำ แผนกวิชาเทคโนโลยีธุรกิจดิจิทัล วิทยาลัยการอาชีพโพนทอง

เลขเวอร์ชันกำหนดที่ `APP_VERSION` ใน `inc/helpers.php` (รูปแบบ หลัก.รอง.แก้ไข) และแสดงที่ท้ายทุกหน้า หน้าเข้าสู่ระบบ คู่มือ และหน้าตั้งค่าระบบ

ระบบหน้าบ้าน–หลังบ้านสำหรับจัดการเรียนการสอนรายวิชาโครงงาน ดูแลโดยหัวหน้างานวิจัย พัฒนานวัตกรรมและสิ่งประดิษฐ์ และร่วมตรวจติดตามโดยฝ่ายวิชาการกับฝ่ายยุทธศาสตร์และแผนงาน

## การติดตั้ง (XAMPP)
1. เปิด Apache และ MySQL ใน XAMPP Control Panel
2. ตรวจค่าฐานข้อมูลใน `config.php` (ค่าเริ่มต้น: root ไม่มีรหัสผ่าน, ฐานข้อมูล `projecthub`)
3. เปิด http://localhost/projecthub แล้วระบบจะพาไปหน้าติดตั้ง กรอกชื่อและรหัสผ่านของผู้ดูแลระบบ
4. ระบบจะสร้างฐานข้อมูล ภาคเรียนปัจจุบัน และรอบการรายงาน 4 รอบให้อัตโนมัติ

ต้องการติดตั้งใหม่ให้ลบไฟล์ `install/install.lock` (และลบฐานข้อมูลเดิมหากต้องการเริ่มจากศูนย์)

## บทบาทผู้ใช้
| บทบาท | สิทธิ์ |
|---|---|
| ผู้ดูแลระบบ | จัดการทุกอย่าง: ภาคเรียน รอบรายงาน รายวิชา ครู กลุ่มผู้เรียน นำเข้าข้อมูล ประกาศ แบบฟอร์ม สำรองข้อมูล รายงาน |
| หัวหน้างานวิจัย พัฒนานวัตกรรมและสิ่งประดิษฐ์ | ดูโครงงานทั้งวิทยาลัย บันทึกผลตรวจติดตาม เขียนสรุปผลรายงานสิ้นภาคเรียน ดูและพิมพ์รายงาน |
| ฝ่ายวิชาการ / ฝ่ายยุทธศาสตร์และแผนงาน | ดูโครงงานทั้งวิทยาลัย บันทึกผลตรวจติดตาม ดูและพิมพ์รายงานสิ้นภาคเรียน |
| ครูผู้สอนวิชาโครงงาน | อนุมัติหัวข้อ นำเข้ากลุ่มโครงงาน ตรวจรายงานเป็นระยะ ให้คะแนน ตัดเกรด เผยแพร่ผลงาน เพิ่ม/แก้ไข/ลบประกาศของตนเอง |
| นักเรียน นักศึกษา | เสนอหัวข้อและสมาชิกกลุ่ม ส่งรายงานความก้าวหน้าพร้อมไฟล์และลิงก์ |

## ลำดับการเริ่มใช้งาน
นักเรียนสมัครได้ที่ `register.php` เลือกกลุ่มเรียนที่มีรายวิชาโครงงานในภาคเรียนที่เปิดอยู่ และเข้าร่วมกลุ่มโครงงานของกลุ่มเรียนนั้นได้ทันที เมื่อตัวโครงงานอนุมัติแล้วจึงส่งรายงานตามรอบเดิมได้ ใช้ฐานข้อมูล **MySQL / MariaDB ผ่าน PDO** และตารางเดิม ไม่ต้องเปลี่ยน schema นักเรียนที่ครูนำเข้าบัญชีไว้แล้วใช้บัญชีเดิมและเมนู *เลือกกลุ่มโครงงาน* เพื่อเข้าร่วมได้

1. **ตั้งค่าระบบ**: ใส่ชื่อผู้ลงนามในรายงาน
2. **ภาคเรียน / กำหนดการรายงาน**: กำหนดวันส่งและคะแนนเต็มของแต่ละรอบ
3. **นำเข้าข้อมูล**
   1. ครูผู้สอน
   2. กลุ่มผู้เรียน (นักเรียนพร้อมกลุ่มเรียน)
   3. การมอบหมายรายวิชาโครงงาน
4. **ครูนำเข้ากลุ่มโครงงาน** ที่หน้ารายวิชา หรือให้นักเรียนเสนอหัวข้อเอง
5. **ระหว่างภาคเรียน**: นักเรียนส่งรายงานเป็นระยะ ครูตรวจ ฝ่ายวิชาการและฝ่ายแผนฯ ตรวจติดตาม
6. **สิ้นภาคเรียน**: ครูบันทึกคะแนนและเกรด แล้วพิมพ์หรือส่งออก **รายงานสิ้นภาคเรียน**

### เมนูนำเข้าข้อมูล (ไฟล์ Excel .xlsx / CSV หรือคัดลอกตารางมาวาง — แถวหัวตารางข้ามให้อัตโนมัติ)
| เมนู | คอลัมน์ |
|---|---|
| แผนกวิชา | ชื่อแผนกวิชา |
| สาขาวิชา | แผนกวิชา, ชื่อสาขาวิชา |
| ครูผู้สอน | รหัสประจำตัว, คำนำหน้า, ชื่อ, นามสกุล, แผนกวิชา, สาขาวิชา, ตำแหน่ง, วุฒิการศึกษา, หน้าที่พิเศษ |
| กลุ่มเรียน | รหัสกลุ่มเรียน, ชื่อกลุ่ม, ระดับชั้น, สาขาวิชา, ปีการศึกษา, ครูที่ปรึกษา |
| นักเรียน นักศึกษา | รหัสนักศึกษา, คำนำหน้า, ชื่อ-สกุล, รหัสกลุ่มเรียน, ชื่อกลุ่มเรียน, ระดับ, แผนกวิชา |
| รายวิชาโครงงาน | ชื่อผู้ใช้ครู, รหัสกลุ่มเรียน, รหัสวิชา, ชื่อวิชา |
| กลุ่มโครงงาน (ที่หน้ารายวิชาของแต่ละกลุ่มเรียน) | กลุ่มที่, ชื่อโครงงาน, รหัสนักศึกษา, หัวหน้า (1 = ใช่) |

ลำดับที่แนะนำ: แผนกวิชา → สาขาวิชา → ครูผู้สอน → กลุ่มเรียน → นักเรียน → รายวิชาโครงงาน → กลุ่มโครงงานที่หน้ารายวิชา (ดาวน์โหลดไฟล์ตัวอย่างได้ในแต่ละหน้านำเข้า)

ผู้ใช้ทุกบทบาทแจ้งปัญหาได้ที่เมนู **แจ้งปัญหาการใช้งาน** ผู้ดูแลระบบเห็นจำนวนเรื่องค้างในเมนูและตอบกลับ / เปลี่ยนสถานะได้
รหัสผ่านเริ่มต้นของผู้ใช้ที่นำเข้า = ชื่อผู้ใช้ หรือรหัสนักศึกษา และระบบจะบังคับให้เปลี่ยนเมื่อเข้าใช้ครั้งแรก

## คู่มือ แบบฟอร์ม และการสำรองข้อมูล
- **ประกาศ**: ครูผู้สอนเข้าเมนู *ประกาศ* เพื่อเพิ่ม แก้ไข และลบประกาศของตนเอง เลือกผู้รับทุกคน / ครู / นักเรียนได้ และเลือกแสดงหน้าเว็บสาธารณะได้ (ประกาศใหม่ของครูเริ่มต้นเป็นภายในระบบ) ผู้ดูแลระบบจัดการประกาศได้ทั้งหมด
- **คู่มือการใช้งาน**: `manual.php` (เปิดได้จากเมนูช่วยเหลือ และหน้าเว็บสาธารณะ) แยกตามบทบาท พิมพ์ / บันทึกเป็น PDF ได้
- **ดาวน์โหลดแบบฟอร์ม**: ผู้ดูแลระบบอัปโหลดที่ *จัดการแบบฟอร์มดาวน์โหลด* กำหนดผู้ดาวน์โหลดได้ (ทุกคน / ครู / นักเรียน) และเลือกเผยแพร่หน้าบ้าน
- **สำรองและกู้คืนข้อมูล**: ไฟล์ .zip (ฐานข้อมูล + ไฟล์แนบ) เก็บที่โฟลเดอร์ `backups/` (เข้าจากเว็บไม่ได้)
  - สำรองอัตโนมัติเมื่อผู้ดูแลระบบเปิดแดชบอร์ดและถึงรอบ หรือตั้ง Windows Task Scheduler ให้รันทุกวัน:
    `C:\xampp\php\php.exe C:\xampp\htdocs\projecthub\backup_cli.php` (เติม `--force` เพื่อสำรองทันที)
  - การกู้คืนจะสำรองข้อมูลปัจจุบันไว้ก่อนเสมอ (ประเภท "ก่อนกู้คืน")
  - ควรดาวน์โหลดไฟล์สำรองไปเก็บนอกเครื่องเซิร์ฟเวอร์เป็นประจำ
